========================================================
  MiniDisc 标签打印生成器 - 经典竖向双列排版重构版
========================================================

【本次核心排版修复】
1. **竖向按列排列（符合音乐 CD/MD 习惯）**：
   - 更改前：01(左) -> 02(右) -> 03(左) -> 04(右)
   - 更改后：01..14(全在左列从上到下) -> 15..28(全在右列从上到下)。
2. **左右两列行数严格对齐**：
   - 自动计算左右两列所需行数，当曲目为奇数时，右列会自动使用占位符保持左右两列行数一致且高度对齐。
3. **行间距绝对均匀**：
   - 采用 Flex Columns + `justify-content: space-between` 布局，彻底解决了拉伸放大后行间距高低不平的问题。
