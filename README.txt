🎵 MiniDisc (MD) 标签设计与打印生成器

一个轻量、高效且易于使用的 MiniDisc (MD) 盘面与外盒标签生成工具。专为 MD 爱好者、音乐收藏者打造，支持高精度打印排版、批量曲目导入以及经典复古设计。

🌟 核心功能与特色

经典竖向按列排版（Column-First）：

遵循传统音乐 CD/MD 歌单阅读习惯，左列填满后自动延伸至右列（如 01~14 在左列，15~28 在右列）。

智能行数对齐与均匀行间距：

左右两列自动平分行数，遇奇数曲目自动占位平齐。

采用 Flex 均匀分布算法，不论放大或缩小标签尺寸，各行间距均保持平滑一致。

高精度打印与多尺寸支持：

预设尺寸：60×40 mm（MD 标准正面）、54×35 mm（小型贴纸）、70×50 mm（外盒/软壳）。

自定义尺寸：支持自由输入宽度与高度（mm）。

多种色彩主题：

简约高对比白：专门为打印机优化，高清晰度。

复古暗黑：适合屏幕展示与暗色风格。

便捷曲目导入：

支持手动输入/粘贴歌单（自动识别序号与时间）。

支持一键导入 .xlsx / .csv Excel 表格数据。

跨平台桌面应用：

提供单文件 Web 版，亦可通过 Python (PyWebView/PyInstaller) 打包为独立的 Windows .exe 桌面程序。

🚀 使用指南

1. 直接通过浏览器打开（无需安装）

双击打开 MiniDisc_Label_Generator.html 即可在任意主流浏览器（Chrome, Edge, Safari, Firefox 等）中使用全部功能。

2. 导出与打印步骤

选择或输入尺寸：在左侧边栏选择预设尺寸（如 60x40 mm）或自定义尺寸。

编辑专辑信息：填写歌手名、专辑名及右上角编号（如 MD-001）。

设置列数：选择“双列”或“单列”。

导入/编辑歌单：

直接在文本框中粘贴歌单（格式示例：01. 曲名 04:15）。

或点击 “导入 XLSX / CSV” 批量加载 Excel 文件。

打印输出：

点击 “打印标签” 按钮。

在弹出的打印预览中，建议将边距设置为 无 或 最小值，缩放比例设置为 100% 或 实际大小。

🛠️ 本地开发与打包为桌面程序 (.exe)

如果你希望将本项目打包为 Windows 独立软件：

前置条件

Python 3.8+

安装依赖库：

pip install pywebview pyinstaller


打包步骤

运行项目根目录下的 build_exe.bat 批处理文件。

打包完成后，将在 dist/ 目录下生成独立的桌面应用程序。
